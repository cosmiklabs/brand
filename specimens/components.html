Implementation notes

Applying the reference

Semantic first

Bind components to background, surface, text, action, and state roles. Both themes redefine every color role. Do not reuse a dark primitive as a light surface.

Visible & named

Pair status with words and a simple symbol. Keep links underlined. Disabled controls use the native disabled attribute and a clear label; never rely on reduced opacity alone.

Room to operate

Standalone controls use a 44 × 44 px house target, beyond WCAG 2.2 AA’s 24 × 24 px minimum and its exceptions. Inline text links remain within the reading flow.

<link rel="stylesheet" href="kits/cosmik/tokens/cosmik.css">
<link rel="stylesheet" href="kits/cosmik/components/controls.css">

<section data-theme="light">
  <button class="c-button c-button--primary" type="button">Apply changes</button>
  <span class="c-select"><select aria-label="Order">…</select></span>
</section>

/* Load the baseline, then any family CSS from its brand-<product>
   repository, then controls.css and your own styles. Set
   data-family="<id>" on the family scope. */

Focus and timing use the kit tokens. Reduced motion removes spatial transitions and the loading pulse. In a real product, announce the start and completion of a pending action and restore its previous focus.

Buttons, links, selects, text fields, chips and the status label use the shared controls layer; tabs, menus, dialogs and layout are specimen-only. Product families load their own token CSS from their brand-<product> repository and keep these controls. See the validation scope and remaining checks.
