03 / Implementation notes

Use the role. Keep the meaning.

Semantic first

Bind components to background, surface, text, action, and state roles. Both themes redefine every color role. Do not reuse a dark primitive as a light surface.

Visible & named

Pair status with words and a simple symbol. Keep links underlined. Disabled controls use the native disabled attribute and a clear label; never rely on reduced opacity alone.

Room to operate

Standalone controls use a 44 × 44 px house target, beyond WCAG 2.2 AA’s 24 × 24 px minimum and its exceptions. Inline text links remain within the reading flow.

<section data-theme="light">
  <button class="button-primary" type="button">Preview project</button>
</section>

.button-primary {
  background: var(--c-action-primary);
  color: var(--c-action-primary-fg);
}
/* Import tokens/cosmik.css, then specimens/components.css. */

Focus: 2 px outline with 2 px offset. Motion: 140 ms state transitions; reduced-motion disables transitions and the loading pulse. In a real product, announce the start and completion of a pending action and restore its previous focus.

Typography: Inter 400 body 17/1.55; Inter 600 display 48/1.1 (34/1.15 on small screens), section 30/1.2, card 22/1.3; Inter 500 controls 15/1.4; IBM Plex Mono 400 labels 14/1.5. Only all-caps labels use 0.06em tracking. See the accompanying validation report for tested scope and limitations.
