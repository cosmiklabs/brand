# Voice, imagery and motion

## Voice

Write like an independent developer sharing useful work: say what a project does, what works today, and what someone can do next. Use "I" for Matthew's personal updates and "Cosmik" for neutral descriptions. Never imply a larger team or a formal company.

**Published description:** "Cosmik is an independent open-source gaming workshop, building games, mods, tools, and modern reimplementations of classic game technology."

**An update:** "[Feature] now works in [build or branch]. [Known limitation] is still being worked on. See [link] for the current setup instructions." Replace each bracket with a verified fact.

Interface copy uses short labels; put clarifications behind an info control, in plain American English rather than jargon.

## Imagery and icons

- Use real project screenshots, diagrams or relevant artwork when they explain the work. Keep proportions; crop only when the essential information stays visible.
- Keep genre imagery (horror included) inside the project it belongs to.
- Avoid generic space wallpaper, decorative starfields and artificial glow as default Cosmik styling.
- Utility icons use one consistent stroke family on a 24 px grid, each with a clear accessible name. Hide decorative icons from assistive technology. An icon never replaces an ambiguous label.

## Motion

The identity animation is still being explored: a centred emblem slides left and reveals widely spaced letters. Its lettering, spacing and timing are not final. Keep recurring interface branding static. Under reduced motion, show the complete identity at once; never delay essential content for a logo reveal. Interface motion uses the motion tokens, which drop to zero under reduced motion.
