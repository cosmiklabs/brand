# Documents

Start from the editable technical-note template in [templates/](../templates/README.md). It carries the identity through type, spacing, restrained branding and clear hierarchy rather than an oversized cover page.

| Element | Rule |
|---|---|
| Page | Letter portrait, 20 mm margins; reflow and review if adapting to A4 |
| Branding | The intact approved raster, or the live identity label; never a retyped wordmark |
| Reading | Inter at the document body size, left aligned, with real Word heading styles |
| Tables and code | Tables for comparable records, with repeated header rows; Plex Mono for code |
| Figures and links | A caption and meaningful alt text; descriptive, visible links |
| Footer | The version or document status and the page number; no invented legal footer |

Replace bracketed fields and remove instruction text. Keep the title and first paragraph specific to the document's purpose. Review every exported PDF page after substantive changes: missing fonts can change the Word layout.
