# HPLX family kit

The family values in `family.json` remain **proposed, pending owner review**. Generate and consume them according to [the token contract](../README.md); selecting an identity asset does not approve the palette, heading type, status hues or elevation.

The selected family symbol is **Ember**, the original diamond above two shallow arcs. See [the HPLX asset kit](../../assets/hplx/README.md) for the transparent SVGs, PNGs, derived platform icons and usage limits. Exact entry points and checksums are in `../../asset-manifest.json` under `entry_points.families.hplx`.

The symbol is independent of the token data. It does not replace the Cosmik parent emblem, change global navigation, or supply an HPLX wordmark or splash composition.
